# TOEI LOOP — 토익 Part 2·3·4 듣기 복습

실행: 이 폴더에서 `python3 server.py`를 실행하고 http://localhost:8000 에 접속합니다. Mac에서는 `start.command`를 더블 클릭해도 됩니다. Python 3 외에 별도 설치나 API 키가 필요하지 않습니다.

음원 파일은 저장소에 포함하지 않습니다. 사용하려는 MP3를 직접 선택하세요.

1. **파일 선택** 또는 드래그 앤 드롭으로 음원을 엽니다.
2. **학습 파트**에서 Part 2·3·4를 선택합니다. 파일명에 `Part 3`, `Part_4`, `파트 2` 등이 있으면 자동 선택합니다. 파일명에 없으면 현재 선택을 사용합니다. 수동으로 변경한 파트는 해당 파일에 대해 기억합니다.
3. Part 2는 7번부터 시작합니다. 문항을 선택하고 **질문 / 보기 A / 보기 B / 보기 C** 버튼으로 해당 구간만 듣습니다. 구간 끝에서 자동으로 멈춥니다.
4. Part 3는 **32–34, 35–37, …**, Part 4는 **71–73, 74–76, …**으로 세 문제씩 표시합니다. 대화/지문과 뒤따르는 질문 읽기를 한 구간으로 재생하며 보기는 별도로 분리하지 않습니다.
5. Part 2의 질문·A·B·C와 Part 3·4 세트 모두 **재생 바**로 원하는 위치를 선택할 수 있습니다. **재생/일시정지**는 현재 위치를 유지하고, **정지**는 해당 구간 시작으로 돌아갑니다. **3초 뒤로 / 3초 앞으로** 버튼은 현재 구간 안에서 이동하며, 일시정지 중에는 위치만 옮깁니다. 문항 전체·보기 연속 재생 버튼도 다시 누르면 일시정지합니다. 아래쪽 공통 플레이어에서도 같은 조작을 할 수 있습니다.
6. 아래 **A·B 손잡이**를 드래그하거나 **현재 위치를 A로 / B로**를 눌러 반복 범위를 지정합니다. 시간은 세트 시작을 0초로 표시하며 숫자로도 수정할 수 있습니다. 범위를 지정하면 **선택 구간 반복**이 켜집니다. **A–B 듣기**는 지정한 시작점부터 재생하며, 반복을 끄면 끝점에서 멈춥니다. **구간 초기화**로 세트 전체 범위를 복원합니다. 반복 범위는 문항마다 저장됩니다.
7. 배속, 문항/세트 전체 재생도 사용할 수 있습니다.
8. 자동 분리가 어긋나면 **구간 조정**에서 시작·끝을 초 단위로 수정합니다. 안내 방송이 길면 자동 분리 설정의 분석 시작 위치를 변경합니다.
9. 별표와 수정 구간은 같은 브라우저의 localStorage에 저장됩니다. 다시 방문하면 같은 음원 파일을 다시 선택하세요. 각 파트의 구간과 별표는 별도로 보관됩니다. 음원 자체는 저장하거나 업로드하지 않습니다.

단축키: Part 2에서 1=질문, 2=A, 3=B, 4=C. Part 3·4에서는 1=세트 전체. Space=재생/일시정지, 좌우 방향키=문항 이동. 입력란이나 버튼에 포커스가 있으면 해당 요소의 기본 키 동작을 사용합니다.

자동 분리는 음성 인식이 아닌 무음 간격 분석입니다. Part 2의 질문·세 보기 구조를 가정하며, 문항 번호는 첫 문항 번호부터 순서대로 부여합니다. 번호 발화 및 보기 알파벳이 별도 구간인 녹음도 처리합니다. 음악, 잡음, 긴 안내 방송, 불규칙한 녹음은 직접 조정이 필요할 수 있습니다. Part 3·4는 긴 발화 구간(15초 이상)을 지문 시작으로 보고 뒤따르는 짧은 질문 발화를 묶습니다. 긴 발화가 없으면 무음으로 구분한 세 구간씩 묶고 확인 메시지를 표시합니다. 긴 안내 방송, 지문 중 긴 정적, 비표준 음원에서는 분석 시작 위치·무음 기준·구간 시간을 조정해야 할 수 있습니다.

서버는 127.0.0.1에만 연결합니다. `index.html`을 직접 열어 파일 선택으로도 사용할 수 있습니다. 서버 종료: 실행한 터미널에서 Ctrl+C.
